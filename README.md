# 📊 Employee Performance Tracker – Excel

## 📌 Project Overview

The **Employee Performance Tracker** is an Excel-based data analysis and dashboard project designed to track employee information, department details, salary data, and performance-related insights.

The project transforms raw employee data into meaningful **KPIs, reports, and interactive dashboards** to help understand employee and departmental trends and support data-driven HR decision-making.

## 🎯 Objectives

* Track and analyze employee-related information
* Analyze employee and department-level data
* Monitor salary-related insights
* Create meaningful KPIs for HR analysis
* Identify trends and patterns in employee data
* Present insights through interactive dashboards and reports

## 📂 Workbook Structure

### 1. Employee Details

Contains employee-level information used for analysis and performance tracking.

### 2. Department Details

Contains department-related information for analyzing employees across different departments.

### 3. Salary Details

Contains salary-related data used to analyze compensation and employee salary patterns.

### 4. Dashboard

An interactive Excel dashboard presenting important KPIs and visual insights in an easy-to-understand format.

### 5. Report

Contains detailed reports generated from the analyzed employee data.

## 📊 Key Analysis

The project includes analysis of:

* Employee distribution
* Department-wise employee analysis
* Salary analysis
* Employee performance insights
* KPI-based HR metrics
* Trends and comparisons across employee and department data

## 🛠️ Tools & Excel Features Used

## 📈 Dashboard

The dashboard provides a visual overview of employee-related KPIs and analysis, making it easier to identify patterns, compare departments, and understand overall employee data.

## 💡 Key Outcome

This project demonstrates how **Microsoft Excel can be used as a data analysis and visualization tool** to convert employee data into actionable HR insights and support data-driven decision-making.
